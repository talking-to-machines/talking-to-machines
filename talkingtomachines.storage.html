Artifact manager.

Manages the run folder structure and orchestrates artifact saving.

      events.csv
      metrics.csv

      agent_table.csv
      group_table.csv
      session_table.csv
      codebook.json
      checkpoints/
        <session_id>.json

talkingtomachines.storage.event_log module

Event logger (Phase 13).

Appends structured event records to a JSONL file. Thread-safe via file lock.

Event types logged:

llm_call, llm_retry, llm_fallback, facilitator_call, facilitator_llm_call, validation_pass, validation_fail, randomisation, group_assignment, treatment_assignment, stop_rule_evaluated, budget_check, tool_call, rag_call, checkpoint_saved, checkpoint_loaded

class talkingtomachines.storage.event_log.EventLogger(log_path: str | pathlib.Path)[source]

Bases: object

Thread-safe append-mode JSONL event logger.

Each event is written as a single JSON line to the log file. File-level thread safety is ensured via a threading.Lock.

_path

Path to the JSONL log file.

_lock

Threading lock used to synchronize concurrent writes.

talkingtomachines.storage.exporters module

Multi-table CSV exporter

Produces research-ready export tables from a completed Session object.

Tables:

session_table.csv — one row per session agent_table.csv — one row per agent per session group_table.csv — one row per group per subsession player.csv — one row per player per subsession assignments.csv — one row per manual assignment or group assignment

Export all research-ready CSV tables to the specified directory.

  • output_dir – Directory where CSV files will be written.

  • start_time – ISO-format timestamp for when the run started.

  • end_time – ISO-format timestamp for when the run ended.

  • total_cost_usd – Cumulative LLM API cost in USD for the run.

A dictionary mapping table name (e.g. "session_table") to its file path.
