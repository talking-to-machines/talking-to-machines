talkingtomachines.analytics.analysis module

Statistical analysis utilities for experiment responses.

This module provides functions that compute summary statistics and analytical metrics from the raw responses collected during an experiment session.

talkingtomachines.analytics.analysis.analyze_results(responses: list) → dict[source]

Analyse raw experiment responses and compute summary metrics.

Parameters:

responses – A list of response records collected from the experiment session.

Returns:

A dictionary of computed analytical metrics. Returns an empty dictionary if an error occurs.

Raises:

Exception – Any unexpected error is caught, logged to stdout, and causes the function to return an empty dictionary.

talkingtomachines.analytics.processing module

Data processing utilities for experiment analytics.

This module provides batch-processing functions that transform raw experiment data into structures suitable for analysis and visualisation.

talkingtomachines.analytics.processing.process_data(data: list) → list[source]

Process a dataset in batches for downstream analytics.

Parameters:

data – A list of raw data records to process.

Returns:

A list of processed records. Returns an empty list if an error occurs during processing.

Raises:

Exception – Any unexpected error is caught, logged to stdout, and causes the function to return an empty list.

talkingtomachines.analytics.visualisation module

Visualisation utilities for experiment results.

This module generates charts and visual artefacts from computed experiment metrics to support exploratory and presentation-ready analysis.

talkingtomachines.analytics.visualisation.visualise_results(metrics: dict) → dict[source]

Generate visualisations from the computed experiment metrics.

Parameters:

metrics – A dictionary of metric names mapped to their computed values.

Returns:

A dictionary mapping visualisation names to their generated artefacts. Returns an empty dictionary if an error occurs.

Raises:

Exception – Any unexpected error is caught, logged to stdout, and causes the function to return an empty dictionary.
